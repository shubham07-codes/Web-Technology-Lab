# Practical No. 1(A)

## Aim

Introduction to Internet.

## Problem Definition

Overview of Internet, E-mail, WWW, Broadband, and FTP.

## Theory

The Internet is a global network that connects computers and devices worldwide using TCP/IP protocols. It provides various services such as E-mail, World Wide Web, file sharing, and online communication. E-mail is used to send and receive electronic messages over the Internet. The World Wide Web (WWW) is a collection of websites and web pages accessed through web browsers using URLs and HTTP. Broadband provides high-speed Internet through technologies such as fiber optic, wireless, DSL, cable, and satellite. FTP, or File Transfer Protocol, is used to transfer files between computers over a network efficiently and reliably.

## Procedure and Execution

### Steps for Implementation

1. Connect the computer to the Internet.
2. Open a web browser such as Chrome, Firefox, or Edge.
3. Enter a website URL in the address bar and open the website.
4. Open an E-mail service such as Gmail.
5. Compose and send an E-mail to understand electronic communication.
6. Observe different broadband connection types such as Fiber, Wi-Fi, DSL, Cable, and Satellite.
7. Study the use of FTP for transferring files between computers.
8. Understand how FTP uses separate connections for control and data transfer.
9. Compare the uses of Internet, WWW, E-mail, Broadband, and FTP.
10. Record the observations and complete the practical.
